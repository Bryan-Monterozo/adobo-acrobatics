# Adobo Acrobatics

**PDF Viewer and Editor totally not based on the infamous PDF editor and signer.**

A free, open-source, privacy-focused PDF viewer and editor built with Next.js and TypeScript.

View, edit, annotate, organize, sign, and manage PDFs directly in your browser. No BS.

### Get started

Install **Node.js 24** and a compatible local npm version, then from the project root:

```sh
npm ci
npm run dev --workspace @adobo/web
```

Open **http://127.0.0.1:3000** and choose a local PDF. For the verified production viewer, build first and run `npm run start --workspace @adobo/web` (port 3100).
