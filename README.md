# Adobo Acrobatics

**PDF Viewer and Editor totally not based on the infamous PDF editor and signer.**

A free, open-source, privacy-focused PDF viewer and editor built with Next.js and TypeScript.

View, edit, annotate, organize, sign, and manage PDFs directly in your browser. No BS.
